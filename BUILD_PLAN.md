# AIPEIISR Build Plan

1. Phase 0: build controls, research, provider matrix, decisions and traceability.
2. Phase 1: FastAPI modular-monolith, SQLAlchemy schema, RBAC/workflow guards, audit, OpenAPI and tests.
3. Phase 2: knowledge layer and public/internal projections.
4. Phase 3: source registry, scheduled RSS/API collection, normalization, hashing, retry/DLQ and health.
5. Phase 4: provider interfaces and bounded AI/background jobs.
6. Phase 5: Next.js public citizen fact-checking and analyst Situation Room.
7. Phase 6: E2E, hardening, observability, Docker deployment and handoff test.

P0 gate: do not start P1 UI/media/pattern enhancements until source -> document -> claim -> evidence -> investigation -> peer review -> human publication and citizen -> submission -> qualified analysis -> escalation work end to end.
